# Segurança

Se você achou uma vulnerabilidade no Lab Desktop, **não abra uma issue pública**. Use o recurso "Report a vulnerability" da aba Security do repositório no GitHub (aviso de segurança privado).

Conte o que viu, como reproduzir e qual versão (`Lab Desktop --versao`, ou Ajustes > Sobre > Copiar informações; a cópia não leva senha, chave nem token).

O desenho de segurança do app (cofre, chave do host, o que o app nunca faz) está em `docs/ARQUITETURA.md`, seções 5, 6 e 13.
