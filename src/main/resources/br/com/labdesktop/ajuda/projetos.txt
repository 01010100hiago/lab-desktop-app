# Como crio, importo ou adiciono um container a um projeto?
@rotulo: Criar e importar projeto
@busca: criar projeto importar git pasta container compose docker node postgres redis imagem
@resumo: Crie um projeto do zero ou importe um que já existe, e depois adicione containers vendo o que muda antes de gravar.
@onde: Novo projeto | Aba Projetos > Novo projeto, ou menu Arquivo > Novo projeto… | projetos
@onde: Adicionar container | Página do projeto > Visão geral > Adicionar container
1. Na aba Projetos, clique em "Novo projeto" (ou use o menu Arquivo, Novo projeto).
2. Escolha "Criar do zero" (pasta nova) ou "Importar" (Git, pasta do seu computador ou pasta do servidor).
3. Para um container, abra a página do projeto, clique em "Adicionar container" e escolha o modelo (Node, Postgres, Redis ou imagem).
4. O app mostra o que muda no docker-compose.yml. Clique em "Gravar no docker-compose.yml" e, se quiser, em "Iniciar o projeto".

## Mais detalhes
O nome do projeto usa letras minúsculas, números e hífen, e é também o nome da pasta. O que já está no projeto nunca é sobrescrito ao importar. Nada é gravado antes do seu clique final.
Para guardar o código com Git, abra o projeto e use "Criar repositório Git" na linha Código da Visão geral, tanto num projeto novo quanto num que já estava iniciado: a janela mostra o que entra antes de criar, e segredos como o .env nunca entram. O tópico Git do projeto explica.
