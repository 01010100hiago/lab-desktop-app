# Como instalo o Git no servidor?
@rotulo: Instalar o Git
@busca: git instalar servidor clonar repositório apt dnf yum apk pacman zypper sudo
@resumo: Importar um projeto por Git precisa do git no servidor; o app confere e, com a sua confirmação, instala.
@onde: Git do servidor | Servidor > Máquina > Git | maquina
@onde: Instalar o Git ao importar | Novo projeto > Importar > Repositório Git > Instalar o Git…
1. Abra Servidor, aba Máquina: o bloco Git diz se o git está instalado.
2. Sem git, clique em "Instalar o Git…". A janela mostra o sistema, o gerenciador de pacotes e os comandos exatos.
3. Se o seu usuário é root ou tem sudo sem senha, clique em "Instalar o Git": o app roda os comandos e confere o git no fim.
4. Se não, a janela mostra o comando para você rodar no Terminal, com Copiar; depois clique em "Já instalei, conferir de novo".
5. Em Novo projeto, Repositório Git, o mesmo aviso e botão aparecem quando falta o git.

## Mais detalhes
O app nunca digita senha de administrador e não mexe na configuração do git. Os gerenciadores que ele conhece são apt-get, dnf, yum, apk, pacman e zypper.
Em Este computador, "Instalar o Git…" abre "Preparar este computador", que mostra o jeito de instalar no seu sistema (Homebrew, ferramentas da Apple ou winget).
Instalar o git é a única coisa que roda no servidor sem depender das ações de escrita ligadas, porque a janela já mostra o que vai rodar e nada roda sem o seu clique.
